데이터:

- 동일 업종 점포 지도 표시
- 반경 300m/500m/1km 점포 수
- 업종별 점포 밀집도

상권위험점수 =
  매출감소율
  점포증가율

출력:
- 경영위험 점수 0~100
- 안정/관심/주의/위험 등급
- 위험 요인 Top 5

입력:

입력:

- 위험점수

출력:
- 현재 상권 상태 요약
- 주요 위험 요인
- 실행 전략
- 금융/상담 연결은 목업 문구로만 표시

수 산식 예시
상권위험점수 =
0.25 * 매출감소위험
+ 0.20 * 점포경쟁위험
+ 0.15 * 폐업증가위험
+ 0.15 * 유동인구감소위험
+ 0.15 * 업종생존율위험
+ 0.10 * 임대료상승위험
등급
0~39: 안정
40~59: 관심
60~79: 주의
80~100: 위험
2.6 개발 시 주의사항
1. 파일명이 한글/공백/괄호를 포함하므로 pathlib.Path 사용
2. CSV 인코딩은 utf-8-sig, cp949, euc-kr 순서로 시도
3. 서울시 데이터는 연도별 파일이 섞여 있으므로 glob으로 로드
4. 동일 컬럼명이 연도별로 다를 수 있으므로 컬럼 표준화 함수 필요
5. 큰 CSV는 처음부터 전체 로딩하지 말고 DuckDB 또는 chunksize 고려
6. 좌표계가 다른 데이터는 지도 표시 전에 WGS84 여부 확인
7. 상권영역 데이터의 좌표계는 EPSG:5181로 안내되어 있으므로 지도 시각화에는 변환 필요
8. PoC에서는 실제 개인사업자 데이터가 없으므로 합성 점포/매출/부채 데이터를 생성해서 사용

## 차별점 1. “상권 분석”이 아니라 “내 점포 위험도”를 계산

서울시 서비스는 상권을 보여줍니다.

우리는 **내 점포가 지금 위험한지**를 보여줘야 합니다.

```
기존 서비스:
이 상권의 매출, 점포 수, 유동인구는 이렇습니다.

우리 서비스:
이 상권 조건에서 내 점포의 매출 구조와 부채 구조를 고려하면
3개월 후 위험도가 높아질 가능성이 있습니다.
```

PoC에서는 실제 내부데이터가 없으니 합성 매출/부채 데이터를 붙입니다.

```
입력:
- 서울시 상권 매출
- 서울시 점포 수
- 서울시 유동인구
- KOSIS 업종 생존율
- ECOS 금리/물가
- 합성 점포 매출
- 합성 대출/현금흐름

출력:
- 경영위험 점수
- 매출 위험 점수
- 부채 체력 점수
- 현금 부족 예상 시점
- 위험 요인 Top 3
```

## 차별점 2. 부채 체력 진단은 서울시 서비스에 없음

기획서 원안에는 **부채 체력 진단 리포트**가 핵심 기능으로 들어가 있습니다. 대출 잔액, 이자 부담, 매출 하락 시 버틸 수 있는 기간 등을 분석하는 구조입니다.

서울시 상권분석서비스는 상권 중심입니다.

반면 우리는 금융사 관점의 **재무 체력/부채 위험/현금흐름 시뮬레이션**을 붙일 수 있습니다.

```
차별화 기능:
- 이자부담률
- 고정비부담률
- 부채상환부담률
- 현금보유개월 수
- 매출 10%, 20% 감소 시 생존 가능 기간
- 금리 1%p 상승 시 월 이자 증가분
```

PoC 문구:

```
서울시 상권분석서비스가 “상권의 상태”를 보여준다면,
본 PoC는 “그 상권 안에서 특정 점포가 얼마나 버틸 수 있는지”를 계산한다.
```

## 차별점 3. 위기 조기경보

서울시 서비스는 주로 현재/과거 데이터를 보여줍니다.

우리는 **이상징후 감지**로 가야 합니다.

```
기존:
최근 분기 매출이 얼마인지 보여줌

우리:
최근 4주 매출 하락 속도가 상권 평균 대비 비정상적으로 빠른지 감지
```

PoC에서 가능한 경보:

```
- 최근 4주 매출 전월 대비 12% 하락
- 유동인구는 유지되는데 점포 매출만 하락
- 동일 업종 점포 수 증가
- 폐업 점포 수 증가
- 프랜차이즈 비율 증가
- 금리 상승으로 이자부담률 악화
```

## 차별점 4. AI 리포트 / 처방

서울시 서비스는 데이터를 보여주는 쪽에 가깝습니다.

우리는 **행동 가이드**를 줘야 합니다.

```
기존:
14~17시 유동인구가 많습니다.

우리:
14~17시 유동인구는 많지만 매출 전환율이 낮습니다.
디저트 세트, 테이크아웃 할인, 재방문 쿠폰을 우선 실행하세요.
```

PoC 리포트 예시:

```
귀 점포는 오후 시간대 유동인구 대비 매출 전환율이 낮습니다.
동일 상권의 카페 업종은 주말 매출 비중이 높지만,
귀 점포의 주말 매출 비중은 낮게 생성되어 있습니다.

단기적으로는 오후 시간대 객단가 상승형 프로모션과
주말 방문 유도 쿠폰을 권장합니다.
```

## 차별점 5. 신한 데이터로 확장 가능한 구조

지금은 공공데이터 PoC지만, 최종적으로는 기획서 원안처럼 신한카드/신한은행 데이터로 확장할 수 있습니다. 기획서에도 신한카드의 실시간 매출 승인, 재방문율, 객단가, 신한은행의 대출잔액, 상환이력, 계좌 입출금 기반 현금흐름 등을 결합하는 구조가 제시되어 있습니다.

발표에서는 이렇게 말하면 됩니다.


아래는 데이터 리포트야
# 데이터 샘플 리포트

from pathlib import Path
import pandas as pd

DATA_DIR = Path("./data")

pd.set_option("display.max_columns", None)
pd.set_option("display.max_colwidth", 80)
pd.set_option("display.width", 300)

files = sorted([
    *DATA_DIR.rglob("*.csv"),
    *DATA_DIR.rglob("*.xlsx"),
    *DATA_DIR.rglob("*.xls"),
])

# json 제외
files = [f for f in files if f.suffix.lower() != ".json"]

print(f"대상 파일 수: {len(files)}")

def read_csv_preview(path, n=2):
    for enc in ["utf-8-sig", "cp949", "euc-kr", "utf-8"]:
        try:
            return pd.read_csv(path, nrows=n, encoding=enc, low_memory=False), enc
        except Exception:
            pass
    return None, None

for i, path in enumerate(files, start=1):
    print("\n" + "=" * 120)
    print(f"[{i}] {path}")
    print("=" * 120)

    try:
        if path.suffix.lower() == ".csv":
            df, enc = read_csv_preview(path, n=2)
            if df is None:
                print("CSV 로드 실패")
                continue

            print(f"형식: CSV / encoding={enc} / columns={len(df.columns)}")
            print("컬럼:", list(df.columns))
            display(df)

        else:
            xls = pd.ExcelFile(path)
            print(f"형식: Excel / sheets={len(xls.sheet_names)}")
            print("시트:", xls.sheet_names)

            for sheet in xls.sheet_names:
                print(f"\n--- Sheet: {sheet} ---")
                df = pd.read_excel(path, sheet_name=sheet, nrows=2)
                print(f"columns={len(df.columns)}")
                print("컬럼:", list(df.columns))
                display(df)

    except Exception as e:
        print("로드 실패:", repr(e))
